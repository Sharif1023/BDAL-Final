\# Amazon Fine Food Reviews Data Analysis Using Hadoop



Big Data analysis of the Amazon Fine Food Reviews dataset using \*\*Hadoop HDFS, Java MapReduce and Apache Pig\*\*.



The project analyzes 568,452 valid Amazon food review records and performs three Java MapReduce analyses and five Apache Pig analyses.



\---



\## Project Objectives



The objectives of this project are:



\- Store a large Amazon review dataset using Hadoop HDFS.

\- Process and summarize review data using Java MapReduce.

\- Perform high-level analytical queries using Apache Pig.

\- Identify important patterns related to reviewers, ratings, products and helpful votes.

\- Visualize analytical results.

\- Demonstrate a complete Hadoop-based Big Data Analytics workflow.
